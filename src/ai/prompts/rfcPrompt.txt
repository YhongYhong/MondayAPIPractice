Validate RFC Excel titles. Output ONLY JSON { "valid": bool, "errors": [{ "sheet": "EXACT JSON KEY", "issue": "desc" }] }. No text, No ```, No COMMENT, No EXPLANATION.

MANDATORY OUTPUT FORMAT (EXACT - NO DEVIATION):
{
  "valid": true/false,
  "errors": [
    {
      "sheet": "sheet name exactly as in input JSON",
      "issue": "issue description"
    }
  ]
}
- If no errors: "valid": true, "errors": []
- If errors: "valid": false, "errors": array of objects (each with "sheet" and "issue")
- "sheet" = EXACT key from Object.keys(jsonInput), e.g., "Request for change"
- "issue" = brief description, if null just null do not comment

SHEET NAMES: Extract from Object.keys(jsonInput) - use EXACT keys in "sheet". Wrong key = { "valid": false, "errors": [] }.

JSON INPUT:
${JSON.stringify(excelJson, null, 2)}

TITLE EXTRACTION RULE (FOCUS - MAIN VALIDATION):
- Extract sheetNames = Object.keys(jsonInput); firstSheet = sheetNames[0]; // e.g., "Request for change"
- Reference: firstSheet row[1][0] (second row, first cell) - trim spaces (raw core, e.g., "Installation of C").
- For each other sheet in sheetNames.slice(1): row[0][0] (first row, first cell) - remove "1. Title:", "Title:", colons, extra spaces (core, e.g., "Installation of ABC"). Must == reference core exactly (case-sensitive).
- Compare all cores to reference. Mismatch? Error: "sheet": "EXACT KEY", "issue": "Core title 'ABC' != reference 'C' from firstSheet row[1][0]".

EXAMPLE (adapt to input):
sheetNames = ["Request for change", "Preparation Task"]
Reference: "Request for change"[1][0] = "Installation of C" (core "Installation of C")
"Preparation Task"[0][0] = "1. Title: Installation of ABC" (core "Installation of ABC") -> Mismatch error for "Preparation Task"

If title mismatch: valid false. Else true, empty errors.

OTHER RULES (BRIEF):
- Date: Each sheet "Configuration Date:" parse = 2025-11-26. Else error "Date not today".
- Anomalies: Empty tables? Error "Anomaly: missing fields".

VERIFY: All "sheet" in sheetNames or fallback valid: false.
